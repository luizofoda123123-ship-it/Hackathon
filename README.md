##🌱 EcoDesafio

##Sobre o projeto


O EcoDesafio é uma plataforma criada para incentivar as pessoas a adotarem hábitos mais sustentáveis e contribuírem para o combate às mudanças climáticas.


A ideia é transformar ações do cotidiano em desafios simples e interativos. O usuário poderá realizar atividades como economizar energia e água, reciclar, evitar desperdício de alimentos, caminhar ou usar bicicleta em vez de carro e cuidar de áreas verdes


##🎯 Objetivo


Nosso objetivo é mostrar que pequenas mudanças nos hábitos podem contribuir para a redução dos impactos ambientais. Além de incentivar essas atitudes, o projeto busca tornar a sustentabilidade mais acessível, simples e divertida.


##🌎 Como vai funcionar?

O usuário recebe desafios sustentáveis e, ao completá-los, ganha pontos e acompanha seu progresso.

Com isso, o projeto incentiva a participação contínua e ajuda as pessoas a perceberem como suas escolhas podem contribuir para um futuro mais sustentável.


##💡 Isso é muito importante?

As mudanças climáticas estão relacionadas principalmente ao aumento das emissões de gases de efeito estufa. Reduzir o desperdício, economizar recursos, diminuir o uso de combustíveis fósseis e preservar o meio ambiente são algumas formas de contribuir para enfrentar esse problema.

O EcoDesafio busca transformar esse conhecimento em ações reais no dia a dia.
